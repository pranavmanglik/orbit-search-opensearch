# Security Policy

Do not report suspected vulnerabilities in public issues. If private vulnerability reporting is enabled for this repository, use GitHub Security Advisories. If unavailable, contact the maintainers privately through the hosting platform. This policy does not imply that a repository setting is enabled. Include a
clear description, impact, and safe reproduction steps. Do not attach credentials or production
data. This alpha package has no published support or response-time commitment.

Use TLS certificate verification and least-privilege OpenSearch credentials. Keep secrets in a
secret manager, rotate them, and avoid logging search cursors or source documents.

## Reporting limits

This package is alpha. No stable-release or response-time commitment is implied by this policy. Do not include credentials, personal data, private keys, or production endpoints in a report.
